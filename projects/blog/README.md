# BruceTang 个人博客系统

> 用最简单的工具，做最实用的东西 —— 这个网站本身就是一个项目。

## 项目简介

基于 docsify + Express 搭建的个人作品集网站，集技术文章、读书笔记、项目展示与社区讨论于一体。前端以 docsify 驱动 Markdown 实时渲染，后端用 Express 提供 API 服务，支持账号体系与内容管理。这也是我实践全栈开发与工程化思维的练兵场。

## 技术栈

| 层级 | 技术选型 | 说明 |
| --- | --- | --- |
| 前端 | docsify 4.x | Markdown 文档站点生成，自定义主题与插件 |
| 后端 | Express 4.21 | RESTful API，JWT 鉴权 |
| 认证 | JWT + bcryptjs | 无状态令牌认证，密码加盐哈希存储 |

## 功能模块

### 前端

- **9 色主题选择器**：6 套亮色 + 3 套暗色主题一键切换，偏好本地持久化
- **响应式设计**：桌面 / 平板 / 手机三端自适应，移动端单列布局
- **SEO 优化**：Open Graph、Twitter Card、sitemap.xml、robots.txt 全套配置

### 后端

- **8 个 API 模块**：认证、文章、书籍、项目、论坛、标签、搜索、统计，各司其职
- **JWT 鉴权**：登录签发令牌，接口中间件统一校验，敏感操作需登录态

### 测试

- **158 个测试用例**，覆盖核心业务逻辑与边界场景
- **覆盖率 92.32%**，持续守护回归质量

### 用户体验

- 回到顶部按钮、阅读进度条、页面加载动画、社交分享按钮
