# 个人博客系统

基于 docsify 搭建的个人作品集网站。

## 项目简介

这个网站本身就是我的一个项目，用来记录和展示我的作品、文章和思考。

## 技术栈

- **框架**：[docsify](https://docsify.js.org/) —— 轻量级文档站点生成器
- **托管**：阿里云 ECS（Ubuntu 22.04）
- **Web 服务器**：Nginx
- **域名**：brucetanghao.com
- **代码托管**：[GitHub](https://github.com/HaoTang9878/tanghao)

## 功能特性

- Markdown 写作，实时渲染
- 侧边栏导航，支持折叠
- 全文搜索
- 代码高亮
- 响应式设计

## 部署方式

1. 代码推送到 GitHub
2. 服务器从 GitHub 拉取最新代码
3. Nginx 直接提供静态文件服务
