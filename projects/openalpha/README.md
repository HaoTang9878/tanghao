# OpenAlpha

> 一个从研究走向工程的量化交易系统 —— 把概率思维变成可执行的代码。

## 项目简介

OpenAlpha 是我正在独立开发的量化交易系统，目标是打通"策略研发 → 历史回测 → 实盘执行 → 风险控制"的完整链路。项目源于我在量化交易方向的实践积累：用核工程里对不确定性的概率思维，去应对市场的随机波动。

系统采用前后端分离架构，前端提供策略编辑与可视化分析界面，后端承载回测引擎与交易执行，数据持久化由 PostgreSQL 负责。

## 技术栈

| 层级 | 技术选型 | 说明 |
| --- | --- | --- |
| 前端 | React + TypeScript | 策略编辑器、回测可视化、收益分析面板 |
| 后端 | Express + TypeScript | RESTful API、回测调度、交易执行 |
| 数据库 | PostgreSQL | 行情数据、策略配置、交易记录持久化 |

## 功能模块

- **策略开发模块**：内置编辑器，支持 PineScript 与 JavaScript 编写交易策略，提供语法高亮与即时校验。
- **回测引擎**：加载历史 K 线数据逐 bar 播放，输出收益率、最大回撤、夏普比率等核心指标，支持参数寻优。
- **实盘交易**：对接主流加密货币交易所 API，支持行情订阅、下单、撤单与持仓查询，回测策略可一键切换至实盘。
- **风险管理**：内置止盈止损、最大仓位限制与单笔风险敞口控制，防止策略异常时造成不可逆亏损。
