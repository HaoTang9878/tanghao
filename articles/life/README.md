## 从核工程到编程

> 转型不是换赛道，而是换一把更锋利的刀。

高考填志愿时我选了核工程，理由朴素得可笑——觉得"核"听起来很酷。进上海交大后，整日与反应堆物理、中子输运打交道，OpenMC 跑一次蒙特卡洛模拟要等几小时，我学会了在等待中读书。

真正接触编程，是从给 OpenMC 写后处理脚本开始的。最初只想把几百个输出文件批量解析成表格，照着教程磕磕绊绊写了几十行 Python，跑通那一刻的成就感不亚于算出一道偏微分方程。从那以后我像发现了新大陆：原本枯燥的重复劳动，几行代码就能交给机器。

后来胃口渐大，从脚本到 Web 应用，从 Python 到 TypeScript，从实验室工具到量化交易系统。核工程教我用概率思维看待不确定性——中子下一次撞到哪谁也说不准，但大数定律会给出稳定的期望；这套思维搬到量化里竟意外契合。

有人说转行可惜，我倒觉得没转——核工程给了我工程素养和对不确定性的敬畏，编程只是换了一把更锋利的刀。

## 深夜 debug 的哲学

> 每个深夜修掉的 bug，都在打磨对细节的耐心和对未知的谦卑。

凌晨两点，屏幕的光是屋里唯一的亮。一个诡异的 bug 卡了我三小时：同样的输入，本地通过，线上挂。咖啡已经凉透，我却越来越清醒。

深夜 debug 有种奇异的专注。白天信息太多——消息、会议把注意力切成碎片；而深夜世界安静下来，大脑终于能把全部算力倾注在一个问题上，这种心流白天很难达到。

bug 最终是个时区问题：本地 UTC+8，服务器 UTC，时间戳差了八小时。找到根因那一刻没有狂喜，只有"果然如此"的平静。修完已三点，我却舍不得睡，又把相关代码重读一遍，怕遗漏同类隐患。

我渐渐觉得 debug 是种修行。它逼你承认自己会犯错，放下"代码应该没问题"的傲慢，一行行核对事实。天亮后回看，那些折磨人的夜晚，反而成了最踏实的记忆。

## 读《活着》有感

> 人是为了活着本身而活着，不为活着之外的任何事物。

余华的《活着》读了两遍。第一遍在高中，只觉得惨——福贵的一生像被命运反复揉搓，亲人一个个先他而去。第二遍在工作后重读，才咂摸出不一样的味道。

福贵年轻时是阔少爷，输光家产气死父亲，命运从此急转直下。被抓壮丁、经历饥荒、丧子丧妻，最后只剩一头也叫"福贵"的老牛陪他耕地。换作别人早崩溃了，可他活下来了，还讲得平平淡淡，像在说别人的故事。

余华说"人是为了活着本身而活着，不为活着之外的任何事物"。年轻时觉得这话消极——活着总得图点什么。现在想来，这恰是最朴素的坚韧：当生活把附加意义一层层剥掉，能稳稳"活着"本身就是胜利。

我们这代没经历饥荒战乱，却有自己的焦虑——内卷、迷茫、意义感缺失。福贵的故事提醒我，别把活着的筹码全压在"得到什么"上。能扛住风雨还在走，就已经很了不起。

## 我的开源之旅

> 所有了不起的事，都是从一行代码开始的。

我的第一个 GitHub 仓库很尴尬——一个只会打印"Hello World"的 Python 脚本，commit message 写着"test"。但那是我第一次把代码推上公网，紧张得像交作业，反复检查有没有泄露密码。

真正理解开源，是从读别人的代码开始。为搞懂一个量化框架的回测逻辑，我把整个仓库 clone 下来逐行读，发现作者把复杂的风控写得像散文一样清晰。那是我第一次直观感受到"好代码"——不是写给自己看的，是写给三个月后的自己和陌生人看的。

后来我开始写文档、提 issue、发 PR。第一次 PR 被合并，开心了一整天——不是因为贡献多大，而是自己的名字出现在别人的项目里，成了某种微小的连接。

开源最迷人的是它的"复利"：你写的代码可能被地球另一端的人读到、用到、改进，再传下去。现在仓库多了些实用项目，但那个 Hello World 我一直没删——它提醒我，所有了不起的事，都从一行代码开始。
